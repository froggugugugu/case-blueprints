# スライサー設定推奨

## ファイル一覧

| ファイル | 用途 | 印刷向き埋込 |
|---|---|---|
| `case-body.3mf` | 本体(推奨) | あり |
| `case-body.stl` | 本体(互換用) | あり(物理的に回転済み) |
| `case-lid.3mf`  | 蓋(推奨) | あり |
| `case-lid.stl`  | 蓋(互換用) | あり(物理的に回転済み) |

3MF を推奨。Bambu Studio / PrusaSlicer / OrcaSlicer などで開けば配置済み。
STL を使う場合も既に印刷向きに回転済みなので、スライサーで再配置不要。

## 印刷向き(物理的に焼き込み済み)

| パーツ | 向き | bed 接地面 | 印刷後の高さ Z |
|---|---|---|---|
| `case-body` | `bottom_down` | -X 端(底面) | 130 mm |
| `case-lid`  | `top_down` | +X 端(上板の外面) | 9 mm |

- 本体: 長軸 X (=125mm 内寸 + 壁 2mm + 底 2mm + 蝶番突出 3mm = 130mm)が垂直に立つ
- 蓋: 上板の外面が bed に接し、嵌合リップ・ラッチ壁・蝶番ナックルが上方に立つ

bed 寸法 210 × 210 × 205mm に対し本体高 130mm は十分余裕。

## サポート

### case-body(必要)

| 部位 | 状況 | 推奨対応 |
|---|---|---|
| 蝶番ナックル(+X 端、-Y 側) | 円柱が水平方向に張り出す。上半分でブリッジング | ツリーサポート、または short overhang 50° 以下 |
| カラビナタブ(+Y 面、+X 端) | 板状の張り出し、印刷終盤に出現 | ツリーサポート(タブ下面のみ) |
| カラビナタブ穴(φ6mm) | 印刷時水平向き、上半分はブリッジング | サポート不要(ブリッジング距離 6mm は PLA で問題なし) |
| ラッチ突起(+Y 面の球形 bump) | 0.6mm 突出、半球 | サポート不要(極小) |
| `RIBBIT GPS module` テキスト(+Z 面) | 0.6mm 盛り上げ、印刷終盤 | サポート不要 |

**推奨設定**:
- ツリーサポート(またはオーガニックサポート)
- サポート対象: タッチビルドプレート + サポート対象オーバーハング
- オーバーハング閾値: 50°
- サポート Z 距離: 0.2mm(剥がしやすさ重視)

### case-lid(原則不要、ナックルのみ注意)

| 部位 | 状況 | 推奨対応 |
|---|---|---|
| 上板(bed 接地面) | 平坦面が bed に密着 | サポート不要 |
| 嵌合リップ(柱状、上方) | 直立、面取り済み | サポート不要 |
| ラッチ壁(+Y 側、上方) | 直立壁 | サポート不要 |
| 蝶番ナックル(中央、bed 接触付近) | 0〜0.5mm の小径柱、水平向き | サポート不要(極短ブリッジ) |

蓋は概してサポート不要。bed adhesion が確保できれば短時間で印刷完了。

## 印刷設定(PLA 推奨)

| 項目 | 推奨値 |
|---|---|
| ノズル温度 | 210℃(初層 215℃) |
| ベッド温度 | 60℃(初層 65℃) |
| 層高 | 0.2mm |
| 初層高 | 0.24mm |
| 壁周回数 | 3(0.4mm ノズル × 3 = 1.2mm 壁厚) |
| インフィル密度 | 20%(屋外・ハードユース時 40%) |
| インフィルパターン | gyroid または cubic |
| 印刷速度 | 50 mm/s(壁・トップ層は 30 mm/s) |
| ファン | 100%(初層 0%) |
| Brim / Skirt | 蓋は brim 5mm 推奨(接地面が小さいため) |

### PETG の場合
- ノズル: 235℃、ベッド: 80℃、ファン: 30〜50%、速度: 40 mm/s
- 蝶番ピンとの摩擦は PETG の方が滑らか

### ABS の場合
- ノズル: 245℃、ベッド: 100℃、エンクロージャ推奨

## テキスト emboss の品質

`RIBBIT GPS module` は **0.6mm 盛り上げ**(=0.2mm 層 × 3 層)。
- ベッド接地ではなく印刷終盤に出現するため層分離リスクは低い
- フォント `ToaHI-Rg.ttf` の細部が出るかは layer height に依存
  - 0.2mm 層: ほぼ問題なし
  - 0.16mm 層以下: より鮮明
  - 0.28mm 層以上: 細部が潰れる可能性あり

## 後処理

### 必須

1. **蝶番ピン挿入**: M2 釘または φ2.0mm 真鍮線/ステンレス線を切って挿入
   - 全長 ≒ Z 方向 27mm + 数 mm(把持代)
   - ピン穴径 φ2.4mm(クリアランス 0.4mm)で挿入容易
2. **嵌合のすり合わせ**: 蓋を初回はめる際、リップ縦エッジが擦るかも → 200 番やすりで軽く落とす

### 既知の小さな干渉(印刷後の調整推奨)

- 蝶番ナックル付近で 35.6 mm³ の幾何重なり(本体ナックル +X 半円 と 蓋上板の -Y 端 1mm 帯)
- **対処**: 蓋の -Y 端を 1mm 程度やすりで落とす、または本体ナックルの +X 半円側を軽く削る
- 印刷時の問題ではなく、CAD 上の重なり。実印刷後に動作確認しながら微調整

### 動作確認

1. 蝶番にピン挿入 → スムーズに回転するか
2. 蓋を閉じる → 嵌合リップが本体内寸に収まり、ラッチが「カチッ」と入るか
3. ラッチ強度 → 蓋が自重・軽い揺れで開かないこと
4. カラビナ通し → 穴に金具が通ること、タブの強度

## トラブルシューティング

| 症状 | 原因候補 | 対処 |
|---|---|---|
| 蓋が硬すぎる | fit_clearance 不足 | `case-config.yaml` の `lid.fit_clearance` を 0.3 に上げて再生成 |
| 蓋がゆるい | fit_clearance 過多 | 0.15 に下げる |
| ラッチが効かない | bump_protrusion 不足 | `catch.bump_protrusion` を 0.8 に増やす |
| ラッチが堅すぎる/外せない | bump_protrusion 過多 | 0.4 に下げる |
| 蝶番が固い | knuckle_clearance_z 不足 | `hinge.knuckle_clearance_z` を 0.6 に増やす |
| 蝶番がガタつく | knuckle_clearance_z 過多 | 0.2 に下げる |

調整後は `python output/design/generator.py` で再生成 → output/print/ の 3MF/STL が更新される。
