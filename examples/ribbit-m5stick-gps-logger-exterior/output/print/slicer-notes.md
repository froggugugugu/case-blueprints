## 今回の更新範囲(2026-05-02 改訂)

| パーツ | 変化 | 推奨アクション |
|---|---|---|
| `case-lid.*` | リップ片側クリア 0.2 → 0.4mm、蓋ナックル Z 高さ片側 0.3mm 縮小、蝶番側非対称クリア +1.1mm | ✓ 再印刷必須(約 30-45 分) |
| `case-body.*` | **本体壁にリリーフカット追加**(蓋ナックル Z 位置に円筒抜き、約 40 mm³ を除去) | ✓ 再印刷推奨 |

### 本体の扱い

**原則**: 本体も再印刷する(CAD 上で完全に整合する状態を保つ)。

- `case-body.3mf` または `.stl` を新規スライス
- リリーフカットが CAD レベルで反映済みなので追加加工不要
- 印刷時間 約 10 時間
- これにより試作 1 号機(リリーフカットなし)は廃番扱い

> **歴史メモ(教訓として残す)**:
> 試作時は「本体再印刷を避けるため既存品を手削り」という選択肢を取った。
> しかしこのアプローチは:
> - 再現性が低い(削る量・形がブレる)
> - 利用者間で品質が揃わない
> - テンプレートの完全性を損なう
>
> その反省から、case-blueprints テンプレートでは「**CAD で解決する**」原則を明文化した
> (case-blueprint/.claude/pitfalls.md P13, P16 / fit-check SKILL.md 参照)。
> 既存印刷品の手削りは「やむを得ない場合の最後の手段」であり推奨ではない。

## 印刷向き(物理的に焼き込み済み)

| パーツ | 向き | bed 接地面 | 印刷後の高さ Z |
|---|---|---|---|
| `case-body` | `bottom_down` | -X 端(底面) | 130 mm |
| `case-lid`  | `top_down` | +X 端(上板の外面) | 9 mm |

- 本体: 長軸 X (=125mm 内寸 + 壁 2mm + 底 2mm + 蝶番突出 3mm = 130mm)が垂直に立つ
- 蓋: 上板の外面が bed に接し、嵌合リップ・ラッチ壁・蝶番ナックルが上方に立つ

bed 寸法 210 × 210 × 205mm に対し本体高 130mm は十分余裕。

## サポート

### case-lid(原則不要、ナックルのみ注意) — 今回の印刷対象

| 部位 | 状況 | 推奨対応 |
|---|---|---|
| 上板(bed 接地面) | 平坦面が bed に密着 | サポート不要、brim 5mm 推奨 |
| 嵌合リップ(柱状、上方) | 直立、面取り済み | サポート不要 |
| ラッチ壁(+Y 側、上方) | 直立壁 | サポート不要 |
| 蝶番ナックル(中央、bed 接触付近) | 0〜0.5mm の小径柱、水平向き | サポート不要(極短ブリッジ) |

蓋は概してサポート不要。bed adhesion が確保できれば短時間で印刷完了(参考: 0.2mm 層 × 約 45 層 ≒ 30-45 分)。

### case-body(参考、再印刷不要)

| 部位 | 状況 | 推奨対応 |
|---|---|---|
| 蝶番ナックル(+X 端、-Y 側) | 円柱が水平方向に張り出す。上半分でブリッジング | ツリーサポート、または short overhang 50° 以下 |
| カラビナタブ(+Y 面、+X 端) | 板状の張り出し、印刷終盤に出現 | ツリーサポート(タブ下面のみ) |
| カラビナタブ穴(φ6mm) | 印刷時水平向き、上半分はブリッジング | サポート不要(ブリッジング距離 6mm は PLA で問題なし) |
| ラッチ突起(+Y 面の球形 bump) | 0.6mm 突出、半球 | サポート不要(極小) |
| `RIBBIT GPS module` テキスト(+Z 面) | 0.6mm 盛り上げ、印刷終盤 | サポート不要 |

## 蓋の重要な寸法(今回の改訂)

| 項目 | 値 |
|---|---|
| 嵌合リップ (Y × Z) | **52.6 × 22.2 mm**(Y 中心が +0.55mm シフト、非対称) |
| ├ リップ -Y 側クリア(蝶番側) | **1.5 mm**(fit 0.4 + lip_hinge_side_extra 1.1) |
| └ リップ +Y 側クリア(ラッチ側) | **0.4 mm**(fit のまま) |
| 蓋プレート -Y 端 → リップ -Y 壁 | 3.5 mm(蝶番ナックル接続〜リップ間のフラット帯) |
| 蓋ナックル Z 高さ | 7.87 mm(本体ナックル間 9.27mm の空きに収まる) |
| 蝶番実効 Z 隙間 | 片側 0.7mm、合計 1.4mm |
| ピン穴径 | φ2.4mm(M2 ピンに対し合計 0.4mm クリアランス) |

→ いずれも前回より緩い嵌合。前回が固すぎた印刷誤差を吸収する設計。

## 後処理

### 必須

1. **蝶番ピン挿入**: M2 釘または φ2.0mm 真鍮線/ステンレス線を切って挿入
   - 全長 ≒ Z 方向 27mm + 数 mm(把持代)
   - ピン穴径 φ2.4mm(クリアランス合計 0.4mm)で挿入容易

### 嵌合がきつい場合(やすりで対処しない)

蓋がきつい・閉まらない場合、**実物でのやすり調整に逃げず CAD で解決する**:
- 全周一律にきつい → `case-config.yaml` の `lid.fit_clearance` を 0.5 に上げて再生成
- 蝶番側だけ擦る → `lip_hinge_side_extra_clearance` を増やす(現在 1.1)
- 蝶番ナックル付近の干渉 → `hinge.body_relief_clearance` を 0.5 に増やして再生成
- いずれも `python output/design/fit_check.py` で根本原因を点検してから対応

### CAD 上の意図的な重なり(ALLOWLIST 管理)

`output/design/fit_check.py` の `ALLOWLIST` を参照:

- 2026-05-02 改訂前: 蝶番ナックル付近で約 35 mm³ の重なりが ALLOWLIST に登録されていた
- 2026-05-02 改訂後: `lid_relief_clearance` 導入で **CAD レベルで解消**、ALLOWLIST から削除
- 現状: `body.intersect(lid)` 重なり = **0.0 mm³**(完全整合)

### 動作確認

1. 蝶番にピン挿入 → スムーズに回転するか
2. 蓋を閉じる → 嵌合リップが本体内寸に **片側 0.4mm の余裕で収まるか**(改訂前は 0.2mm で干渉した)
3. ラッチが「カチッ」と入るか
4. ラッチ強度 → 蓋が自重・軽い揺れで開かないこと
5. カラビナ通し → 穴に金具が通ること、タブの強度

## トラブルシューティング

| 症状 | 原因候補 | 対処 |
|---|---|---|
| 蓋が硬すぎる | fit_clearance 不足 | `case-config.yaml` の `lid.fit_clearance` を 0.5 に上げて再生成 |
| 蓋がゆるい | fit_clearance 過多 | 0.3 に下げる |
| ラッチが効かない | bump_protrusion 不足 | `catch.bump_protrusion` を 0.8 に増やす |
| ラッチが堅すぎる/外せない | bump_protrusion 過多 | 0.4 に下げる |
| 蝶番が固い | lid_knuckle_extra_clearance_z 不足 | `hinge.lid_knuckle_extra_clearance_z` を 0.5 に増やす(本体ナックル位置は不変のまま蓋ナックルだけ縮める) |
| 蝶番がガタつく | lid_knuckle_extra_clearance_z 過多 | 0.2 に下げる |
| 蝶番ピンが入りにくい | pin_clearance 不足 | `hinge.pin_clearance` を 0.6 に増やす |
| 蓋を閉じる時、蝶番付近で蓋シリンダーが擦る | body_relief_clearance 不足 | `hinge.body_relief_clearance` を 0.5 に増やして再生成 |

調整後は `python output/design/generator.py` で再生成 → output/print/ の 3MF/STL が更新される。
**本体側 STL は `knuckle_clearance_z` を変えない限り不変**(本体再印刷不要)。
