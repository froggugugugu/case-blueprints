# input/ — 人間が編集する領域

ワークフロー 5 段階のうち、**人間が触るすべてのファイルがここに集約**されます。

| サブディレクトリ | 段階 | 役割 |
|---|---|---|
| `objects/` | 1 | ケースに収納するオブジェクトを 1 つ 1 ファイルで採寸記録 |
| `requirements/` | 2 | ケース全体への要件(Claude 初稿、人間補正可) |
| `design-params/` | 3 | L2 の主要編集対象。寸法・選択肢のパラメータ |
| `feedback/` | 4 | 構造変更や曖昧な要望を日本語で記述 |

🚧 各段階のスキーマ・記入ガイドは構築過程で追加されます。
