# skills/ — 7 つの skill

5 段階ワークフロー + プロジェクトリード + 機構特化スキルの計 7 つを定義します。

## プロジェクトリード(進行管理)

| スキル | 役割 |
|---|---|
| `/lead` | プロジェクトリード(PdM 相当)。現状を確認し、次の選択肢を AskUserQuestion で提示しながらワークフローを回す。途中での採寸し直しや方針転換も受け入れる。人格・キャラクター付けはなし、行動規範のみ |

## 各段階のスキル

| スキル | 段階 | 役割 |
|---|---|---|
| `/measure` | 1 | AskUserQuestion で対話的に採寸 → `input/objects/<id>.yaml` |
| `/design` | 2-3 | 要件統合 + CadQuery 生成 + validator |
| `/review-fix` | 4 | フィードバックを読み取り設計を更新 |
| `/fit-check` | 4-5 (橋渡し) | パーツ間の嵌合・接合面・蝶番組合せの干渉/クリアランスを点検 |
| `/export` | 5 | 最終 STL / 3MF + スライサー設定 |

## 機構特化スキル(横断)

| スキル | 役割 |
|---|---|
| `/hinged-lid` | ヒンジ蓋ケース特化(本体/蓋/レバーの 3 部品)。M2 ピン/ねじ長尺セット(M2×30 ねじ + M2×28 平行ピン)をデフォルトに、`hardware:` プリセット差替えで幅狭ラッチ・別径構成にも転用可。`/design` 確定後の closure 詳細を埋める |

機構特化スキルは段階に属さず、必要に応じて呼び出す **横断スキル**。
将来 `/screw-mount` `/magnet-latch` 等を追加する際もこの分類に入れる
(無闇に増やさない方針は維持)。

## 推奨フロー

```
/lead を起動 → 状態判定 → 必要な skill を都度呼ぶ
                  ↑
   ユーザーは「もう良い」と言うまで対話継続
```

または直接 skill を呼ぶ:

```
measure → design → review-fix(必要に応じ反復)→ fit-check → export
                       ↑                             ↓
                       └─── 失敗時は review-fix へ ──┘

closure が hinge_lever のとき、design 後 or review-fix 中に:
                  → hinged-lid(具体寸法を埋める / プリセット切替)
```

`/lead` は進行管理に徹し、各 skill の責務を侵しません。
詳細は各 SKILL.md を参照。
